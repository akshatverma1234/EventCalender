# 🗓️ Custom Event Calendar App

A modern and responsive event calendar built with **React**, **Tailwind CSS**, and **Vite**. This application allows users to manage events through an intuitive UI — with support for adding, editing, deleting, and drag-and-drop rescheduling of events.

---

## 🚀 Features

1. **📅 Monthly View Calendar**  
   - Displays days of the current month with correct alignment and empty slots.
   - Highlights today’s date for quick reference.

2. **📝 Event Management**  
   - **Add Event:** Users can add a new event with a title, time, and optional recurrence.
   - **Edit Event:** Users can update event details by selecting an existing event.
   - **Delete Event:** Easily remove events with a delete icon in the event preview.

## 🛠️ Tech Stack

- ✅ **React** – Frontend component-based architecture  
- 🎨 **Tailwind CSS** – Utility-first styling  
- ⚡ **Vite** – Lightning-fast dev environment  
- 🧠 **React Hooks** – State and event logic  
- 🎯 **@dnd-kit** – Drag-and-drop support

## 📦 Getting Started

Follow these steps to run the app locally:

```bash
# 1. Clone the repository
git clone https://github.com/your-username/custom-event-calendar.git
cd custom-event-calendar

# 2. Install project dependencies
npm install

# 3. Start the development server
npm run dev
